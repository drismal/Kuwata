# Kuwata — функциональная окклюзионная поверхность по методике М. Куваты

Desktop-приложение (Windows, .NET 8, WPF) для зубного техника: по суставным параметрам пациента,
сведённой паре сканов челюстей и размерам центрального резца рассчитывает наклоны скатов
жевательных зубов по формулам Куваты и строит в 3D окклюзионную поверхность (кривые Шпее
и Уилсона) в системе координат артикулятора Amann Girrbach Artex CR.

Источник методики: M. Kuwata, *Color Atlas of Ceramo-Metal Technology*, Vol. I–II (1986).
Выписка формул — [`docs/KUWATA_METHOD.md`](docs/KUWATA_METHOD.md), принятые решения —
[`docs/DECISIONS.md`](docs/DECISIONS.md).

## Что умеет (v0.2)
- Импорт STL/OBJ: верхняя и нижняя челюсть (сведённый прикус), суставные головки из КТ.
- Перенос в систему артикулятора: сканы уже в ней / матрица лицевой дуги / по КТ
  (головки + орбитале, центр головки — подбор сферы) / средние значения (Бонвиль, Балквилл).
- Ориентиры указываются кликом по модели.
- Overbite/overjet — автоматически по сканам или по ориентирам, с ручной коррекцией.
- Формулы Куваты: WP, BP, P3, угол раскрытия, допуски по зубам 4–7, угол Беннета по Ханау.
- Анализатор Бродрика (ASP, MPSP/CPSP, OPSC, R = 4″), кривая Уилсона, 3D-поверхность.
- Кинематика Artex CR: протрузия, латеротрузия (RC = 0, Беннет), ретрузия в пределах long centric;
  анимация нижней челюсти в 3D.
- Динамическая проверка по Кувате: наклон траекторий бугров 6 в кинематике против WP / BP / P3 по формулам.
- Проверка контактов: протрузия — без контактов жевательных; латеротрузия — без балансирующих
  и без рабочего 7, групповая функция на рабочей стороне; ретрузия — без интерференций в пределах LC.
- 3D-просмотр со слоями, отчёт, проект в одном файле `*.kwp`.
- Экспорт STL в координатах исходных сканов (exocad / 3Shape) или артикулятора,
  JSON с настройками Artex CR и матрицей переноса.

## Не входит в v0.1 (следующие этапы)
Адаптация зубов из библиотеки, виртуальный FGP для верхних зубов, просмотр DICOM.

## Сборка
```
dotnet test tests/Kuwata.Core.Tests     # ядро — собирается и тестируется на любой ОС
dotnet run --project src/Kuwata.App     # приложение — только Windows
```
Готовая сборка для Windows — артефакт `Kuwata-win-x64` в GitHub Actions (workflow `build`).

## Система координат
X — вправо (сторона пациента), Y — вперёд, Z — вверх, мм. Начало — середина шарнирной оси.
Горизонталь XY — ось-орбитальная плоскость; все углы Куваты отсчитываются от неё.

## Структура
- `src/Kuwata.Core` — расчёты, геометрия, форматы, проект (без UI).
- `src/Kuwata.App` — WPF-приложение, 3D на HelixToolkit.
- `tests/Kuwata.Core.Tests` — тесты, включая контрольный пример (ССП 45°, A1 = A2 = 40°, A3 = 45°).
