# Решения по реализации

Принцип: **всё по Кувате**. Где в книге есть ответ — делаем по книге. Где ответа нет — берём решение
из `KUWATA_METHOD.md` (метка [РЕШЕНИЕ]) с исправлениями ниже. Ничего сверх этого не придумываем.

## Порядок расчёта (как в книге)
1. Фронтальная направляющая A1 / A2 / A3 (строится первой — Шуйлер, т.2 с.253).
2. Наклоны скатов жевательных зубов WP / BP / P3 из направляющей и суставных путей (т.1 с.145–147, 199–201).
3. Окклюзионная плоскость (кривая Шпее) — анализатор Бродрика, R = 4″ (т.1 с.185–193).

Кривая Шпее и глубина плоскости у Куваты **не зависят** от ССП и угла Беннета. Суставные углы
определяют только наклоны скатов. Угол Беннета в формулы не входит: он нужен для кинематики
и для настройки артикулятора.

## Исправления к KUWATA_METHOD.md
1. **Кривая Уилсона.** Центр — на серединном перпендикуляре к отрезку между точками справа и слева
   (а не строго на средней линии), иначе при разной высоте сторон окружность не строится.
   При симметрии совпадает с исходным решением.
2. **Правило BP** — наклон внутренних скатов ≤ BP (формулировка в разделе 3 исправлена).
3. **OB / OJ** измеряются в осях артикулятора (Z — вертикаль, Y — сагиттальная горизонталь),
   чтобы A3 отсчитывался от горизонтали артикулятора. OJ — горизонтальное расстояние между
   режущими краями (хорда пути скольжения). OB ≤ 0 → A3 = 0 (предупреждение), OJ ≤ 0 → 90°.
   Для клыков горизонтальная составляющая — по оси X (первое приближение; уточняется кинематикой).
4. **P3 по сторонам:** P3_R = (A3 + ССП_R)/2, P3_L = (A3 + ССП_L)/2.
5. **Щёчно-язычные ширины** для правила 55–60 % добавлены по Уилеру
   (верх 4–7: 9.0 / 9.0 / 11.0 / 11.0; низ 4–7: 7.5 / 8.0 / 10.5 / 10.0) — **требуют сверки**.
6. **Верхние жевательные зубы** — виртуальный FGP (огибающая движений нижних) — этап кинематики.
7. **Угол раскрытия** сравнивается с шаблонами A (100°) / B (140°) т.1 с.208 — справочно в отчёте.

## Геометрия поверхности
- Флаг Бродрика — сагиттальная проекция (плоскость YZ артикулятора) на каждой стороне.
- Линия щёчных бугров в плане — прямая через ASP и мезиально-щёчный бугор нижнего 6.
- z(x, y) = Шпее(y) + W(x) − W(x_щёчн(y)): на линии щёчных бугров поверхность лежит ровно на кривой Шпее,
  язычнее — ниже по кривой Уилсона.
- Зона: от ASP кзади до MPSP − 2 мм (или 50 мм, если MPSP не задан); полоса 10 мм язычно и 2 мм щёчно.

## Artex CR — требует сверки с документацией Amann Girrbach
`src/Kuwata.Core/Articulator/ArtexCr.cs`: межмыщелковое 110 мм, радиус мыщелкового элемента 5 мм (для CPSP),
диапазоны ССП / Беннета / ретрузии. Эти числа не входят в формулы Куваты, но влияют на CPSP,
режим средних значений и предупреждения. Отдельно проверить, от какой плоскости откалиброваны
шкалы ССП на Artex CR (ось-орбитальная или франкфуртская).

## Кинематика (раздел 11)
- Артикулятор задаёт движение нижней челюсти; верхняя неподвижна. Мыщелки — центры Artex (±55, 0, 0).
- Протрузия: мыщелки по ССП своей стороны, резцовая точка по A3; при разных ССП положение —
  метод Хорна (МНК) по трём точкам.
- Латеротрузия: RC = 0 — рабочий мыщелок только латерально; балансирующий — направление
  (tg Беннета, 1, −tg ССП); резцовая точка опускается по A1/A2 относительно горизонтального смещения.
  Неизвестные — поворот (3) и латеральный сдвиг (1), метод Ньютона с продолжением по параметру.
  Немедленный боковой сдвиг в книге не используется — не моделируется.
- Ретрузия: горизонтальный сдвиг кзади, не больше long centric.
- Резцовая точка — режущий край нижнего центрального резца (ориентир или автоопределение).
- Параметр движения — путь мыщелка (балансирующего при латеротрузии), мм.

## Проверка контактов
- Контакт: знаковое расстояние от вершины нижней до поверхности верхней < 0.1 мм.
- Интерференция: проникновение > 0.05 мм и глубже, чем в ЦО, на 0.05 мм.
- Шаги: 0.5, 1, 2, 3, 4, 5 мм; ретрузия — до long centric.
- Участки: фронт — кпереди от ASP − 1 мм; второй моляр — дистальнее мезиально-щёчного бугра 6
  на (ширина нижнего 6 − 2.5) мм; между ними — премоляры и первый моляр.
- Знак расстояния берётся по нормалям STL верхней челюсти — сетка должна быть ориентирована наружу
  (обычно так и есть у сканеров).
- Проверка выполняется на загруженной нижней челюсти: для контроля дизайна загрузите
  восковую модель / экспорт из CAD вместо нижней.
