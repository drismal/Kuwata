## 1. Цели окклюзии (концепция — групповая функция)

**[КНИГА]** т.1 с.153, т.2 с.253:
1. В центрическом соотношении — контакт как можно большего числа зубов.
2. Окклюзионная нагрузка направлена по длинной оси зуба и распределена равномерно.
3. Протрузия: контактируют как можно больше фронтальных зубов; премоляры и моляры **никогда** не контактируют.
4. Латеротрузия: на рабочей стороне контактируют клык и жевательные зубы, **кроме вторых моляров**; на балансирующей стороне — **никогда**.
5. Если клыки отсутствуют или стоят неправильно, ведущим зубом служит первый премоляр (т.2 с.253).
6. Фронтальная направляющая строится **до** жевательных зубов (Шуйлер, 1953; т.2 с.253).

**[КНИГА]** Контакты фронта в ЦО — вариант C (т.2 с.254): резцы контактируют в центрическом соотношении, точечно, на мезиальном и дистальном маргинальных гребнях нёбной поверхности верхних резцов. Вертикальный размер при этом не меняется.

Все варианты из книги:
- A — резцы не контактируют ни в ЦС, ни в ЦО;
- B — нет контакта в ЦС, есть в ЦО;
- C — контакт в ЦС (выбран автором);
- D — контакт в long centric.

**[КНИГА]** Клык при боковом движении имеет линейный контакт рабочей поверхности. Центральные и боковые резцы — точечный, узкий или без контакта, по случаю (т.2 с.259).

## 2. Обозначения углов

| Символ | Значение |
|---|---|
| A1 | Угол фронтальной (клыковой) направляющей на рабочей стороне при движении **вправо** |
| A2 | То же при движении **влево** |
| A3 | Угол фронтальной направляющей при протрузии |
| C1 / C2 | Угол суставного пути на балансирующей стороне (C1 — правый мыщелок, C2 — левый) |
| C3 | Сагиттальный суставной путь (ССП) |
| RC1 / RC2 | Поворот рабочего мыщелка; **у Куваты всегда = 0°** |
| WP1 / WP2 | Наклон скатов моляров на **рабочей** стороне (вправо / влево) |
| BP1 / BP2 | Наклон скатов моляров на **балансирующей** стороне |
| P3 | Наклон скатов моляров в сагиттальной плоскости (протрузия) |

**[КНИГА]** Все углы отсчитываются от горизонтали артикулятора.
**[РЕШЕНИЕ]** Горизонталь — ось-орбитальная плоскость (не франкфуртская).

## 3. Формулы Куваты

**[КНИГА]** т.1 с.145–147 и с.199–201; т.2 с.305 (те же формулы для верхних жевательных зубов, техника F.G.P.).

```
(i)   WP1 = (A1 + RC1) / 2,   RC1 = 0   →  WP1 = A1 / 2
(v)   WP2 = (A2 + RC2) / 2,   RC2 = 0   →  WP2 = A2 / 2
(ii)  BP2 = (A1 + C2) / 2     — балансирующая (левая) сторона при движении вправо
(iv)  BP1 = (A2 + C1) / 2     — балансирующая (правая) сторона при движении влево
(iii) P3  = (A3 + C3) / 2       — в программе по сторонам: P3_R = (A3 + ССП_R)/2, P3_L = (A3 + ССП_L)/2
Угол раскрытия (deployment angle):
      правая сторона: 180° − (WP1 + BP1)
      левая сторона:  180° − (WP2 + BP2)
```

Правила применения **[КНИГА]**:
- **BP** — наклон внутренних скатов моляров не должен превышать BP. Иначе возникнут балансирующие контакты (т.1 с.147). *(Формулировка исправлена: в исходной редакции ТЗ соотношение было записано наоборот.)*
- **WP** — значение для групповой функции; по нему ориентировочно определяются ширина контактной зоны и кривизна щёчных бугров (т.1 с.147). Язычные скаты нижних моляров на рабочей стороне делаются **положе** линии WP (т.1 с.201).
- **P3** — фактический наклон скатов делается **меньше** расчётного, иначе будут контакты моляров при протрузии. Мелкое перекрытие резцов и пологий ССП дают пологий P3 (т.1 с.201).
- Автор прямо пишет: числа ориентировочные, клинически пользоваться только ими непрактично. На практике угол раскрытия получают **динамически** — двигая артикулятор по фронтальной направляющей (т.1 с.201). Это обосновывает обязательную проверку в виртуальном артикуляторе.
- Метод Доусона (1974): заполнить резцовый столик воском, провести штифт вправо и влево — получится запись угла раскрытия (т.1 с.201).

⚠ **Неоднозначность в книге.** На с.147 A3 описан как «угол направляющей **клыка** при протрузии», на с.201 — как «угол фронтальной направляющей при движении вперёд».
**[РЕШЕНИЕ]** A3 = arctg(overbite / overjet) центральных резцов.

## 4. Угол Беннета по Ханау

**[КНИГА]** т.1 с.136. Артикулятор Hanau 145-2, ССП справа и слева 45°:

```
L = H / 8 + 12        (L — угол Беннета, H — ССП)
пример: 45/8 + 12 = 17.6°
```

**[РЕШЕНИЕ]** Применяется, только если угол Беннета не введён вручную.

## 5. Окклюзионная плоскость — анализатор Бродрика (система P.M.S.)

**[КНИГА]** т.1 с.153, 185–193.

- Система P.M.S. (Pankey, Mann, Schuyler). Радиус **4 дюйма = 101.6 мм** — из теории сферы Монсона. По Монсону, 4″ подходит почти во всех случаях (с.193).
- «Кривая Шпее» здесь — в понимании P.M.S., а не в исходном смысле Шпее (1890) (с.153).

Построение (на каждой стороне отдельно):

1. **ASP** (anterior survey point) — на нижнем клыке, между вершиной бугра и дистальным краем (line angle). Чем ближе ASP к дистальному краю, тем **ниже** окклюзионная поверхность. От ASP проводится дуга R = 4″ — «линия ASP» (с.186–187).
2. Задняя точка, одна из двух (с.188–189):
   - **MPSP** (molar posterior survey point) — дистощёчный бугор нижнего второго моляра;
   - **CPSP** (condylar posterior survey point) — передняя сторона мыщелкового стержня артикулятора.
   
   От неё тоже проводится дуга R = 4″.
3. Пересечение дуги задней точки с линией ASP — «точка деления» (bisecting point). На линии ASP выбирается **OPSC** (occlusal plane survey center) (с.189).
4. Положение OPSC (с.190–191):
   - **кпереди** от точки деления — бугры нижних моляров **выше**;
   - **кзади** — бугры **ниже**;
   - Кувата ставит OPSC **немного кзади** от точки деления;
   - на практике положение OPSC проверяется по межокклюзионному пространству: при установленной верхней модели нож должен проходить между верхними и нижними культями с учётом толщины материала.
5. Из OPSC радиусом 4″ вырезается окклюзионная поверхность нижних жевательных зубов. Радиус уменьшают постепенно, малыми шагами, до итоговых 4″ (с.192).
6. **Кривую Уилсона этот метод не задаёт** (с.192: «the curve of Wilson remains unaffected»).
7. Если радиус больше 4″, кривизна становится резкой — учитывать при построении (с.193).

**[РЕШЕНИЕ]**
- Центр OPSC свой для каждой стороны.
- Сдвиг OPSC кзади — параметр, по умолчанию 2 мм вдоль дуги ASP.
- Кривая Уилсона — отдельный радиус во фронтальной плоскости (по умолчанию 4″), центр по средней линии над дугой. Проходит через высоты кривой Шпее справа и слева в области первых моляров; щёчные бугры нижних моляров выше язычных.

## 6. Форма жевательных зубов

**[КНИГА]**
- Расстояние между щёчным и язычным буграми — **55–60 %** максимальной щёчно-язычной ширины коронки (т.1 с.65, 159, 194, 216).
- Расстояние от вершины щёчного бугра до центральной ямки почти равно расстоянию от язычного бугра до ямки (т.1 с.216).
- Нужен больший угол раскрытия — добавить воск в центральную ямку и укоротить язычные бугры антагонистов (т.1 с.196).
- Шаблоны «бугор — ямка» (т.1 с.208):
  - A: угол 100°, наклон бугра к ямке 30°;
  - B: угол 140°, наклон бугра к ямке 20°.
- Рабочий скат при групповой функции: угол θ (между нагрузкой в ЦО и нагрузкой при боковом движении) ≈ **30°** (Шуйлер, 1963; т.2 с.259). Больше — избыточная боковая нагрузка.
- Протрузия при моделировании — прямолинейная.

## 7. Long centric

**[КНИГА]** Столик Long Centric Freedom настраивается согласованно с резцовым штифтом (т.1 с.142). Свобода из ЦО на нижнем моляре закладывается при моделировании (т.1 с.196). Числового значения в книге нет.

**[РЕШЕНИЕ]** Ретрузионный контроль = long centric. Свобода кзади по умолчанию 0.5 мм, задаётся пользователем.

## 9. Размеры коронок (классические средние, Уилер)

**[РЕШЕНИЕ]** Масштаб от центрального резца пациента:
- k_ш = ширина резца / 8.5;
- k_в = длина резца / 10.5.

Размер зуба = табличное значение × k (ширина × k_ш, высота × k_в).

| Зуб | Верх: ширина × высота, мм | Низ: ширина × высота, мм |
|---|---|---|
| 1 | 8.5 × 10.5 | 5.0 × 9.0 |
| 2 | 6.5 × 9.0 | 5.5 × 9.5 |
| 3 | 7.5 × 10.0 | 7.0 × 11.0 |
| 4 | 7.0 × 8.5 | 7.0 × 8.5 |
| 5 | 6.5 × 8.5 | 7.0 × 8.0 |
| 6 | 10.0 × 7.5 | 11.0 × 7.5 |
| 7 | 9.0 × 7.0 | 10.5 × 7.0 |

## 10. Допуски по зубам

**[РЕШЕНИЕ]** Для каждой стороны, i = 0, 1, 2, 3 для зубов 4, 5, 6, 7:

```
запас_i  = 5° + 2° × i
P3_i     = P3_стороны − запас_i
BP_i     = BP_стороны − запас_i     (правая сторона: BP1, левая: BP2)
WP_i     = WP_стороны − запас_i     (правая: WP1, левая: WP2)
допуск_i = min(P3_i, BP_i)
```

Предупреждения:
- A1 или A2 вне 20–40° — далеко от ориентира Шуйлера 30°;
- A3 ≤ 0 — нет перекрытия;
- допуск < 8° — бугры почти плоские.

Пример контрольного расчёта (ССП 45°, Беннет не введён): Беннет по Ханау = 17.6°.

## 11. Система координат и артикулятор

**[РЕШЕНИЕ]**
- Оси: X — вправо (сторона пациента), Y — вперёд, Z — вверх. Начало — середина шарнирной оси.
- Горизонталь XY = ось-орбитальная плоскость: центры суставных головок справа и слева + орбитальная точка.
- Режим без КТ (средние значения):
  - сторона треугольника Бонвиля 110 мм;
  - угол Балквилла 22°;
  - окклюзионная плоскость к ось-орбитальной 10°.
- Артикулятор: Amann Girrbach Artex CR. Экспорт в exocad — STL в исходных координатах сканов + параметры артикулятора.

Кинематика (реализация v0.1, проверена тестами):
- **Протрузия.** Мыщелки идут по ССП своей стороны, резцовая точка — по A3. Жёсткое преобразование подбирается методом Хорна.
- **Латеротрузия.** RC = 0: рабочий мыщелок смещается только латерально (сдвиг Беннета). Балансирующий мыщелок идёт по направлению (Беннет в горизонтальной плоскости, ССП в сагиттальной). Резцовая точка опускается по A1/A2 относительно своего горизонтального смещения. Неизвестные — вектор поворота (3) и латеральный сдвиг (1); решение методом Ньютона.
- **Ретрузия.** Горизонтальный сдвиг кзади, ограниченный long centric.

Проверки на артикуляторе:
- протрузия — нет контактов жевательных зубов;
- латеротрузия — нет контактов на балансирующей стороне, на рабочей стороне контакт есть (групповая функция);
- ретрузия — нет контактов на скатах в пределах LC.

## 12. Адаптация зуба из библиотеки (реализация v0.1)

**[РЕШЕНИЕ]**
1. Масштаб по размерам из раздела 9. Ориентация по осям библиотеки: окклюзия и мезиальная сторона задаются пользователем.
2. Наклон по Уилсону: моляры — 100 % наклона кривой, премоляры — 50 %. Щёчные бугры выше язычных.
3. Поворот по касательной к кривой Шпее, затем остаточный изгиб по кривизне.
4. Самая высокая точка относительно кривой ставится **ровно на кривую** (вершины щёчных бугров нижних зубов на кривой Шпее).
5. Направленные углы скатов, отсчёт от горизонтали артикулятора, 90-й перцентиль:
   - протрузионные (нижние — обращённые мезиально, верхние — дистально) ≤ P3_i;
   - балансирующие внутренние (нижние — обращённые язычно, верхние — щёчно) ≤ BP_i;
   - рабочие на язычных буграх нижних — сравнение с WP_i, только предупреждение.
6. Сжатие рельефа вокруг вершин бугров (вершины неподвижны, ямки поднимаются) бинарным поиском до выполнения допусков. Минимум 35 % исходного рельефа. Переход к краю коронки распределяется по всей высоте — край коронки остаётся на месте.
7. Передние зубы: режущий край — в точку клика, без кривой Шпее.
